# Linux Fundamentals

Linux was an important starting point in my cybersecurity learning journey. I practiced using the command line and solving tasks rather than only memorizing commands.

## Topics Practiced

### File System and Basic Commands
- Navigating directories and paths
- Reading, creating, copying, moving, and removing files
- Understanding absolute and relative paths

Commands practiced include:

```bash
pwd
ls
cd
cat
less
head
tail
mkdir
cp
mv
rm
```

### Searching and Text Processing

```bash
find
grep
sort
uniq
strings
xxd
```

### Redirection and Command Execution

```bash
>
>>
<
|
2>/dev/null
&
&&
```

### Other Topics
- Users, groups, and file permissions
- SSH and remote access
- Base64 and ROT13
- Archives and compression, including `tar`
- Basic use of `nc` and `openssl`
- Basic Git concepts

## Key Takeaway

I am learning to choose commands based on the problem, interpret their output, and combine tools when useful.
