# Networking Fundamentals

Networking is a current focus of my cybersecurity studies. I am learning how devices communicate and how networking concepts appear in practical traffic analysis.

## Topics Studied

### IPv4
- IPv4 addresses and 32-bit representation
- Four octets and values from 0 to 255
- Network portion and host portion

### Subnetting
- Subnet masks
- Network IDs and host addresses
- CIDR notation
- Basic subnet calculations

### Protocols and Communication
- TCP and UDP
- Source and destination ports
- Client/server communication
- ARP
- HTTP and HTTPS

## Practice

I use learning exercises, network simulations, and Wireshark packet captures to connect theory with practical examples.

## Current Goal

Build a reliable networking foundation before progressing to reconnaissance, enumeration, and more advanced security labs.
