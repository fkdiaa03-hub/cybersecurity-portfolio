# IPv4 Addressing

## Learning Objectives

- Understand that an IPv4 address is 32 bits long.
- Recognize the four octets in dotted-decimal notation.
- Understand that each octet has a value from 0 to 255.
- Distinguish the network portion from the host portion using the subnet mask or prefix length.
