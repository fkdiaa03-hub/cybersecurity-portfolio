# OverTheWire Bandit

## Overview

I completed the OverTheWire Bandit wargame as part of my Linux and cybersecurity training.

The challenges provided hands-on practice with Linux commands, permissions, SSH, encoded data, compressed files, networking tools, and Git.

## Skills Practiced

- Linux command line and file inspection
- Searching with `find` and `grep`
- Text processing with `strings`, `sort`, and `uniq`
- File permissions
- SSH and SSH keys
- Base64 and ROT13
- Hexadecimal data
- Archives and compression
- Basic network utilities, including `nc` and `openssl s_client`
- Git and repository concepts

## Problem-Solving Approach

1. Read the task carefully.
2. Identify the available clues.
3. Choose a suitable command or tool.
4. Inspect the output.
5. Adjust the approach if needed.
6. Record the concept learned.

## Outcome

Completing Bandit improved my confidence with Linux and command-line problem solving and prepared me to continue into networking and traffic-analysis exercises.

Passwords, credentials, and flags are intentionally not published.
