#  Networking Fundamentals

Networking is the current foundation of my cybersecurity studies.

I am learning how devices communicate and how networking concepts can be analyzed from a security perspective.

##  Topics

### IPv4

* IPv4 addresses
* 32-bit representation
* Four octets
* Values from 0–255
* Network portion
* Host portion

### Subnetting

* Subnet masks
* Network ID
* Host addresses
* CIDR
* Basic subnet calculations

### Ports & Protocols

* TCP
* UDP
* Source ports
* Destination ports
* Network services

### Client / Server

The client initiates a request and the server receives the request and provides a response or service.

```text
Client  ───── Request ─────> Server
Client  <──── Response ───── Server
```

### ARP

I am studying how ARP maps IPv4 addresses to MAC addresses on a local network and why ARP is important from a security perspective.

### HTTP / HTTPS

I am learning the difference between unencrypted HTTP communication and encrypted HTTPS communication.
