# Linux Fundamentals

Linux was the starting point of my practical cybersecurity learning journey.

I focused on becoming comfortable with the command line and understanding how Linux systems work rather than simply memorizing commands.

## Topics Practiced

### File System

* Navigating directories
* Absolute and relative paths
* Creating files and directories
* Copying and moving files
* Removing files and directories
* Reading file contents

### Basic Commands

```text
pwd
ls
cd
cat
less
head
tail
mkdir
cp
mv
rm
```

### Searching

```text
find
grep
```

I practiced finding files and searching for specific information inside files.

### Text Processing

```text
sort
uniq
strings
xxd
```

### Redirection

```text
>
>>
<
|
2>/dev/null
```

### Command Execution

I practiced:

```text
&
&&
```

and learned how commands can be combined to create more useful workflows.

### Permissions

I learned the basics of:

* Linux permissions
* Users
* Groups
* Read / Write / Execute permissions
* File ownership
* `chmod`

### Remote Access

I practiced SSH and learned how remote Linux systems can be accessed securely.

### Encoding and Compression

I worked with:

* Base64
* ROT13
* Hexadecimal data
* `tar`
* Compression formats

### Networking Tools

I practiced basic tools including:

* `nc`
* `openssl`

### Git

I also practiced basic Git concepts while working through security exercises.

## Main Lesson

Linux command-line knowledge is an important foundation for cybersecurity.

The main goal was to understand why and when a command is useful instead of memorizing commands without understanding them.
