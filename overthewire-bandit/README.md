# OverTheWire Bandit

## Overview

I completed the OverTheWire Bandit wargame as part of my Linux and cybersecurity training.

Bandit provided practical challenges that required using Linux commands, understanding file permissions, working with SSH, decoding information, handling compressed files, and solving problems using the command line.

## Skills Practiced

* Linux command line
* File and directory inspection
* File searching
* `find`
* `grep`
* `strings`
* `sort`
* `uniq`
* File permissions
* SSH
* Network connections
* `nc`
* `openssl s_client`
* Base64
* ROT13
* Hexadecimal data
* Compression
* Archives
* Git
* SSH keys
* Bash fundamentals

## Problem-Solving Skills

Bandit taught me to:

1. Read the task carefully.
2. Identify what information is available.
3. Choose an appropriate Linux command.
4. Combine commands when necessary.
5. Analyze the output.
6. Adjust the approach when the first attempt fails.

## Security Concepts

The challenges introduced practical ideas related to:

* Authentication
* File permissions
* Remote access
* Network services
* Encoded data
* SSH keys
* Git repositories
* Command-line investigation

## Outcome

Completing Bandit improved my confidence with the Linux command line and gave me a practical foundation for moving into networking and security labs.

Credentials, passwords, and flags are intentionally not published.
